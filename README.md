# Sathvika Boina | AI & Backend Engineer Portfolio

This is a production-grade, highly modular Next.js application representing the digital identity and professional portfolio of Sathvika Boina.

## Architecture

Built with a modular feature-driven architecture:
- `src/features/`
  - `ai-assistant/` - Intelligent documentation assistant bridging local knowledge base.
  - `projects/` - Case studies, evidence, timelines.
  - `research/` - Academic works, citations, abstracts.
  - `achievements/` - Verified wins categorized elegantly.
  - `skills/` - Evidence-based competency matrix.
  - `terminal/` - Fully interactive command line interface.

## Tech Stack
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS, Vanilla CSS for custom tokens
- **Animations**: Framer Motion
- **State Management**: Zustand
- **Icons**: Lucide React

## Local Development

```bash
# Install dependencies
npm install

# Start the development server
npm run dev

# Run linting
npm run lint

# Run strict type checking
npm run type-check (or npx tsc --noEmit)
```
